# Wii U Pro Controller

Separate from [Wii Remote](../wii-remote/index.md). Kernel Bluetooth match covers Wii product IDs rather than a dedicated Pro PID; the Pro product string or extension type selects its built-in controls. Linux source exposes 17 digital controls, four stick axes, four LEDs, battery infrastructure and on/off rumble, not Remote IR/acceleration or MotionPlus. [`wiiupro-pa2-kernel-bluetooth-match`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-kernel-bluetooth-match.json), [`wiiupro-pa2-kernel-pro-classification`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-kernel-pro-classification.json), [`wiiupro-pa2-kernel-pro-input`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-kernel-pro-input.json), [`wiiupro-pa2-kernel-pro-mode`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-kernel-pro-mode.json), [`wiiupro-pa2-kernel-pro-output-power`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-kernel-pro-output-power.json).

SDL recognizes the built-in extension, reads report `0x3d`, maps 15 buttons and six axes (including digital triggers), and interprets coarse power status. Cemu's native Wiimote path excludes the Pro; this does not rule out generic input. [`wiiupro-pa2-sdl-pro-detection`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-sdl-pro-detection.json), [`wiiupro-pa2-sdl-pro-mapping`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-sdl-pro-mapping.json), [`wiiupro-pa2-sdl-pro-power`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-sdl-pro-power.json), [`wiiupro-pa2-sdl-pro-report`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-sdl-pro-report.json), [`wiiupro-pa2-cemu-native-pro-exclusion`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-cemu-native-pro-exclusion.json). These are source-only consumer paths; physical identity, calibration and virtual acceptance remain unmeasured: [`wiiupro-pa2-physical-identity-gap`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-physical-identity-gap.json), [`wiiupro-pa2-physical-calibration-gap`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-physical-calibration-gap.json), [`wiiupro-pa2-virtual-acceptance-gap`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/wiiupro-pa2-virtual-acceptance-gap.json).
