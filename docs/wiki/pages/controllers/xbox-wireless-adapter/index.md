## Source-only consumer evidence

- Out-of-tree xone handles USB adapter GIP transport; the pinned mainline xpad table does not match those adapter products. This is a bounded negative about xpad, not all Linux drivers. [`rcv-xwa-mainline-xpad`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-mainline-xpad.json).
- Ordered association/removal work manages live clients separately from receiver binding. A first-free 16-entry table is software capacity, not measured simultaneous connections. [`rcv-xwa-association-queue`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-association-queue.json), [`rcv-xwa-slot-reuse`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-slot-reuse.json).
- Input objects are registered after client identification and destroyed on client removal. Rejoining creates a new instance; evdev path reuse is unknown. SDL Linux evdev discovery is source-described, not a live selected-backend test. [`rcv-xwa-node-lifetime`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-node-lifetime.json), [`rcv-xwa-sdl-linux`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-sdl-linux.json).
- A live client routes GIP data/audio through shared USB queues; physical delivery during loss is unknown. Each gamepad can expose battery and LED surfaces; separately identified headsets can expose ALSA audio. Reviewed paths do not create keyboard/pointer companions. [`rcv-xwa-output-routing`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-output-routing.json), [`rcv-xwa-per-client-surfaces`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-per-client-surfaces.json).
- Client loss leaves siblings allocated; receiver disconnect or reset-resume removes all clients. Shared fault fairness and recovery timing are unmeasured. [`rcv-xwa-failure-teardown`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-failure-teardown.json).

## Inferred virtual boundary

Standalone evdev and UHID cannot establish native xone USB adapter binding. USB-level presentation is an untested possibility, not a validated adapter. [`rcv-xwa-virtual-boundary`](https://github.com/anderstvoss/controller-protocol-research/blob/eb7887bf1aacc1b0baf6f5e973cac2ee41090c4e/records/claim/rcv-xwa-virtual-boundary.json). No physical receiver or host experiment was performed.
