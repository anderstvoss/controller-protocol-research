## Acceptance ordering

Use **SDL3 3.4.10 or later as a targeted native reference**, retaining exact SDL source/binary revision; also run 3.4.0 as a regression control if available. First perform a separately bound/unbound consumer matrix from B to isolate kernel handoff; then test Steam-only; then shared SDL+Steam. Record independently the raw identity and interface/usage numbers, device node ownership and udev tags, open/read/write return values, decoded gamepad input, sensor controls, IMU opt-in, haptic writes, lizard state, closing order and failure cleanup. A green evtest trace is *not* proof that SDL or Steam native HIDAPI accepts the device.

**Unresolved:** Steam client closed-source discovery/open/report policy; InputPlumber/HHD direct 2026 implementation; Unity bundled SDL/runtime-specific report behavior; real 2026 descriptors, calibration, firmware, report timing and host permissions. All are **No evidence** until a specific pinned implementation or lab result is recovered. Puck, Bluetooth, LEDs/audio intentionally excluded.
