# Switch 2 GameCube Controller — bounded physical capture plan

**GameCube USB research, prep for #296** · **not run**. Owner hardware available: one Switch 2 GameCube controller. No original GameCube controller and no WUP-028 adapter are available. Capture only this USB-connected unit. Nothing here constitutes a controlled experiment or promoted physical claim. No USB-device or virtualgamepad implementation is requested in this plan.

## Capture policy and safety

Operator-controlled, versioned tooling only; separate raw private files from any eventual public sanitized derivative. Before public release, remove all device-specific identifier values, serials, addresses, USB topology paths, machine paths, personal labels and wall-clock timestamps; retain only relative monotonic timing and non-identifying structural categories. Never include realistic example identifier literals or placeholder strings. Keep raw bytes private and never commit them. Preserve USB interface descriptors privately until reviewed; redact strings and any identifying value. No firmware updates, pairing changes or calibration writes. Each session has a predefined stop condition, fresh re-enumeration where indicated and an independent idle baseline. Record both successful responses and timeouts without guessing missing traffic.

## Operator log fields

Record hardware generation/revision if independently labeled, host OS/kernel and controller driver, SDL runtime exact version, tool hash and command, monotonic session duration, transfer type, expected report type, reply presence, retry/timeouts, failure mode, redaction ledger and after-review derived-claim IDs. Avoid serial/address-like example data anywhere. Re-run a source-only check after proposed promotion; do not infer independence from two consumers decoding the same unvalidated physical trace.

**Not an adapter capture plan:** no WUP-028, original pad or WaveBird is present. `gc-adapter-descriptors-unknown`, `gc-adapter-remaining-status-unknown` and `gc-adapter-rumble-brake-value` retain source-only/unknown status independently of this Switch 2 hardware.
